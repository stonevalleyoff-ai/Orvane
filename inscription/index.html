01 / NOUVELLE CONNEXION

Inscrire un jeu

Deux clés pour relier votre jeu au monde commun. La clé publique accompagne votre code ; la clé d’administration reste secrète.

CONNEXION CRÉÉE

Les clés de

Identifiant
Clé du jeu · publique : elle va dans le code du jeu, elle signe ses dépôts
Clé d'administration · secrète : elle règle le jeu, elle ne va jamais dans le jeu

Orvane ne garde que l'empreinte de la clé d'administration : elle ne s'affichera plus, et perdue, elle ne se retrouve pas. Rangez-la maintenant, dans un gestionnaire de mots de passe ou dans le fichier ci-dessous.

Les étapes suivantes

  1. Lire le monde : chaque jour, sans clé. Il est publié à 03:17 UTC.

  2. Traduire : relier les terrains du jeu aux 24 biomes d'Orvane, et faire de chaque lignée une créature, là où elle vit et en proportion de son effectif.
    3. 
    
  3. Renvoyer des pressions : ce que font les joueurs, en comptes bruts, avec la clé du jeu.

    4. 
    
  4. Régler l'exposition : facultatif, plus bas, avec la clé d'administration.

02 / ADAPTER LE VIVANT
Régler l'exposition

  
L'exposition dit ce que le jeu sait montrer : la compression des raretés, l'étalement des changements, les traits qu'il sait dessiner. Sans exposition, les lots du jeu sont lus tels quels. Le schéma complet est profil.schema.json, propriété exposition.
